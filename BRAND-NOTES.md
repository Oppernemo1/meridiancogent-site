## Colors

- Navy `#1E2761` — primary, dominant
- Ice blue `#CADCFC` — supporting, used on navy backgrounds
- Body text gray `#2C2C2A`
- Secondary text gray `#5F5E5A`
- (Reserved status colors, from the product UI — not used in the logo itself)
  - Green `#2C6E49` — cleared/positive
  - Amber `#B7791F` — warning
  - Red `#9B2C2C` — blocking

## Typography

- Headings / "Meridian": serif — Georgia or Times New Roman as web-safe fallback. If you license a font later, a book-weight serif (e.g. Tiempos, Source Serif) matches the current direction.
- Body / "Cogent" and UI text: sans-serif — Helvetica/Arial fallback, or a grotesque (e.g. Inter, Söhne) if licensing a font.
- This serif/sans split (serif for weight and trust, sans for clarity) is already used across the product UI — keep it consistent between site, product, and logo.

## Usage rules

- Minimum clear space around the mark: half the mark's height, on all sides.
- Don't recolor the mark outside navy/ice without a specific reason (e.g. single-color print — use all-navy or all-white).
- Don't stretch, skew, or add drop shadows/gradients/outlines to either mark.
- On dark or photographic backgrounds, use the transparent mark with stroke color flipped to ice `#CADCFC`, or the full navy-box version if enough contrast isn't guaranteed.
- SVGs are fully vector — safe to scale to any size (favicon through billboard) with no quality loss.

## Two directions, side by side

- **Line Graph M** — a zigzag reading as both the initial "M" and a progress/tracking line. Versatile, works at any size, most "software" of the two.
- **Execution Stroke** — a single unbroken pen stroke ending in a lift-off dot, read as a signature closing a deal ("signed, sealed, executed"). More distinctive and harder to copy, slightly more editorial/premium in feel, marginally less legible at very small sizes (favicon) — test before committing.
