# MeridianCogent — Brand Assets

## Files in this set

| File | Use |
|---|---|
| `public/logo-mark.svg` / `.png` | Icon alone, primary treatment (graphite background, orange stroke). Favicon, app icon, social avatar, JSON-LD `logo`. |
| `public/logo-full.svg` | Mark + wordmark, no tagline. Dark-ground (knockout) treatment — used in the graphite header/footer, the only place the full lockup appears. |
| `public/email/logo-mark.png` | Icon alone, knockout treatment (orange background, graphite stroke) — used in the email header, which is also graphite. |
| `src/app/icon.svg` | Favicon — same as the primary mark. |

## Colors

- Graphite `#2B2F3A` — primary, dark grounds and headings
- Signal orange `#E8743B` — fills, the logo mark, rules/strokes, small labels on dark grounds
- Orange (text on light) `#C4562A` — links, section labels, emphasis on a light ground (the bright orange fails AA as body text)
- Body text `#2A2C31`
- Secondary text `#63676F`
- Page ground (paper) `#FBFAF8`
- (Reserved status colors, from the product UI — not used in the logo itself)
  - Green `#2C6E49` — cleared/positive
  - Red `#9B2C2C` — blocking

## Typography

- Headings / "Meridian": serif — system serif stack (Georgia/Times New Roman fallback).
- Body / "Cogent" and UI text: sans-serif — system sans stack (Helvetica/Arial fallback).
- This serif/sans split (serif for weight and trust, sans for clarity) is already used across the product UI — keep it consistent between site, product, and logo.

## Usage rules

- Minimum clear space around the mark: half the mark's height, on all sides.
- Don't recolor the mark outside graphite/orange without a specific reason (e.g. single-color print — use all-graphite or all-white).
- Don't stretch, skew, or add drop shadows/gradients/outlines to either mark.
- The mark shape itself (the zigzag "M") is unchanged — only the fill/stroke colors flip between the primary treatment (graphite fill, orange stroke) and the knockout treatment (orange fill, graphite stroke) used on the graphite header/footer/email band.
- SVGs are fully vector — safe to scale to any size (favicon through billboard) with no quality loss.

## The mark

**Line Graph M** — a zigzag reading as both the initial "M" and a progress/tracking line. Versatile, works at any size.
